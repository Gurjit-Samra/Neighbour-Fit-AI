- Main tradeoff
- Best-fit lifestyle label

   - Tradeoff: Higher noise and potentially higher rent.
   - Best for: Urban, social, car-light lifestyle.

## Recommendation Engine Requirements

Use an explainable hybrid scoring system.

The final score should combine:

- Budget Fit
- Walkability Fit
- Transit Fit
- Nightlife & Social Fit
- Safety Fit
- Fitness & Wellness Fit
- Pet Fit, only if the user has a pet
- Workplace Fit
- Penalties for poor fit

Do not use a black-box ML model. This should be a deterministic, explainable recommendation system based on normalized feature scores and user importance weights.

## Data Normalization Requirements

The dataset may contain values like:
- High
- Medium
- Low
- Very High
- Very Low
- Strong
- Moderate
- Poor
- Good
- Excellent
- Numeric scores
- Currency strings like "$1,650"

Create robust normalization helpers that can convert these values into 0–1 scores.

Suggested mappings:

Excellent / Very High / Strong = 1.0  
High / Good = 0.8  
Medium / Moderate / Average = 0.5  
Low / Poor = 0.25  
Very Low / Very Poor = 0.1  
Missing / Unknown = 0.5

For inverse values like crime, noise, and car dependency:
- First normalize the original value
- Then calculate inverse as 1 - normalized value

For currency columns:
- Strip "$" and commas
- Convert to number

## Budget Fit Logic

Budget should be treated as both a constraint and a score.

Use Avg 1BR Rent as the main rent comparison.

Budget Fit:
- If Avg 1BR Rent <= 90% of user budget: 1.0
- If Avg 1BR Rent <= 100% of user budget: 0.9
- If Avg 1BR Rent <= 110% of user budget: 0.65
- If Avg 1BR Rent <= 125% of user budget: 0.35
- If Avg 1BR Rent > 125% of user budget: 0.1

Apply penalties:
- 0–5% over budget: -2 points
- 5–10% over budget: -5 points
- 10–20% over budget: -12 points
- More than 20% over budget: -25 points or exclude from top 5 unless there are not enough results

Final Budget Score formula:
Budget Score =
0.75 × Rent Fit
+ 0.15 × Affordability normalized
+ 0.10 × Affordability Score normalized

If Affordability or Affordability Score is missing, use Rent Fit as the fallback.

## User Weighting Logic

The lifestyle sliders are importance weights, not direct scores.

Use the following values:
- Walkability importance
- Transit importance
- Nightlife importance
- Safety importance
- Fitness importance
- Workplace importance

If Pet = Yes:
- Add Pet importance = 60

If Pet = No:
- Pet importance = 0

Normalize weights:

Normalized Weight = individual importance / total importance

If all importance sliders are 0:
Use default weights:
- Walkability: 15
- Transit: 15
- Nightlife: 10
- Safety: 25
- Fitness: 10
- Workplace: 25
- Pet: 0 unless pet is yes

## Final Score Formula

Calculate:

Weighted Lifestyle Fit =
WalkabilityWeight × WalkabilityScore
+ TransitWeight × TransitScore
+ NightlifeWeight × NightlifeScore
+ SafetyWeight × SafetyScore
+ FitnessWeight × FitnessScore
+ WorkplaceWeight × WorkplaceScore
+ PetWeight × PetScore

Final Score =
0.25 × BudgetScore
+ 0.75 × WeightedLifestyleFit

Then convert to percentage:

Final Match Percentage = Final Score × 100 - Penalties

Clamp final score between 0 and 100.
